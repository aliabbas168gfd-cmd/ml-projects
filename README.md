Machine Learning Projects
This repository contains machine learning projects built during my study of machine learning algorithms.

Projects

1. Customer Segmentation using K-Means
Unsupervised machine learning project to segment customers based on:

visit frequency
discount usage.

Algorithm:
K-Means Clustering

Applications:
Helps marketplaces target customers with personalized offers.

2. Loan Approval Prediction
Supervised machine learning project to predict whether a loan application will be approved or rejected.

Algorithms used:
Logistic Regression
KNN
Naive Bayes

Features:
Applicant income
Loan amount
Credit history
Education
Marital status
